# ajustar-presupuestos-y-publicidad-megaline
Este proyecto consiste en un análisis de mercado y rentabilidad para la operadora de telecomunicaciones Megaline, con el objetivo principal de optimizar el presupuesto de publicidad.

Se trata de un estudio donde se analizan los datos de comportamiento de los clientes durante 2018 para evaluar el desempeño financiero de los dos planes prepago que ofrece la empresa: Surf y Ultimate. A través del procesamiento de registros de llamadas, mensajes y uso de internet, el proyecto calcula los ingresos reales generados por cada usuario para determinar cuál de los dos planes es más rentable y así proporcionar al departamento comercial una recomendación basada en datos sobre dónde enfocar la estrategia de marketing para maximizar las ganancias.
